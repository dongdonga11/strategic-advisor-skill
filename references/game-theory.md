# Game Theory

## 1. 基本原则

博弈分析不是猜测别人“会不会使坏”，而是分析：

- 各方目标
- 各方可用行动
- 各方掌握的信息
- 各方承担的成本
- 各方对结果的预期
- 行动之间的相互依赖

## 3. 行动推演

对每个关键行动，至少推演三层：

1. 我方采取行动
2. 对方最可能的反应
3. 对方反应后的二阶后果

必要时继续分析第四层：

4. 我方如何调整，或者对方如何反制

## 4. 反应类型

常见反应包括：

- 忽视
- 跟随
- 降价
- 模仿
- 封锁渠道
- 提高资源获取成本
- 联合其他参与者
- 改变规则
- 转向替代市场
- 延迟行动，观察我方投入

不要默认对手会采取最愚蠢或最恶意的行动。应优先选择符合其利益、能力和历史行为的反应。

## 5. 信息与信号

区分：

- 公开承诺
- 真实行动
- 可验证信号
- 廉价表态
- 战略性误导
- 不完整信息

可靠信号通常具有成本、约束或可验证后果。只说“不做某事”通常不如承担实际成本的行动可信。

## 6. 先手与后手

分析谁拥有：

- 先行动权
- 观察权
- 规则制定权
- 退出权
- 延迟权
- 否决权
- 替代方案

有时不立即行动能够保留更多信息和选择权。延迟不是拖延，而是有条件地等待更高价值信息。

## 7. 博弈中的边界

每次推演都应明确：

- 最坏结果
- 可接受损失
- 不可触碰底线
- 止损条件
- 退出路径
- 触发重新评估的信号

## 9. 合规边界

博弈分析用于合法竞争、谈判、风险管理和决策优化。不得将其用于欺诈、胁迫、非法操纵、内幕交易、骚扰或伤害他人。
