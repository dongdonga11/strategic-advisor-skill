# Strategic Analysis

## 1. 分析目标

战略分析不是罗列信息，而是回答：

1. 当前系统如何运转？
2. 谁从中获益，谁承担成本？
3. 哪些变量真正决定结果？
4. 我方能够改变哪些变量？
5. 最值得优先验证的行动是什么？

## 2. 系统拆解

### 参与者

识别所有关键角色：

- 付费者
- 使用者
- 交付者
- 资源提供者
- 渠道方
- 平台方
- 监管方
- 潜在替代者
- 竞争者

### 流程

绘制从需求产生到价值交付的完整链路：

```text
需求 → 获客 → 转化 → 交付 → 复购/扩散 → 现金回收
```

### 流量与资源

分别分析：

- 信息流：谁知道什么？
- 资金流：钱从哪里来、流向哪里？
- 资源流：关键资源如何获得？
- 权力流：谁能制定规则或改变条件？
- 信任流：谁拥有用户信任？

## 3. 价值链分析

对每个环节追问：

- 这个环节创造了什么价值？
- 谁愿意为它付费？
- 它的成本是什么？
- 它是否稀缺、不可替代或难以复制？
- 它是否掌握客户关系、数据、标准或入口？
- 它是否存在效率、体验或信任缺口？

重点寻找四类机会：

1. 被忽略的高价值环节
2. 成本高但可被重构的环节
3. 信息不对称严重的环节
4. 被平台或头部企业遗留的细分需求

## 4. 核心矛盾识别

区分以下层次：

- 表面诉求：用户说自己想要什么
- 真实目标：用户最终想得到什么
- 结构约束：为什么现状难以改变
- 核心矛盾：哪个冲突限制了系统表现
- 可控变量：我方能够直接或间接改变什么

不要把“缺少努力”当作默认解释。优先检查：

- 目标是否冲突
- 激励是否错位
- 信息是否不对称
- 资源是否受限
- 流程是否存在瓶颈
- 规则是否使参与者无法采取正确行动

## 5. 杠杆点判断

优先级通常取决于：

```text
杠杆价值 = 影响范围 × 变化幅度 × 可控程度 ÷ 实施成本
```

这不是精确数学公式，而是帮助排序的思考工具。

高价值杠杆往往具有以下特征：

- 能影响多个环节
- 能改变激励而非只增加努力
- 能降低关键成本
- 能获得稀缺信息
- 能提高转换率或复购率
- 能减少对单一渠道的依赖
- 能形成反馈回路或网络效应

## 6. 竞争分析

不要只比较功能和价格，还要比较：

- 客户获取方式
- 交付成本
- 供应链与资源
- 品牌与信任
- 数据积累
- 组织速度
- 合作网络
- 规则与渠道控制力
- 退出成本与迁移成本

## 7. 输出格式

完成分析后，默认输出：

1. 一句话判断
2. 系统结构图
3. 关键参与者与利益
4. 核心矛盾
5. 关键杠杆
6. 三个战略选项
7. 推荐方案及理由
8. 第一阶段行动
9. 风险与验证信号
