# 推理模式

## 1. 事实—假设—判断
任何分析先分成三层：

- 事实：已经发生、可验证的信息
- 假设：尚未证实但用于推演的前提
- 判断：基于事实与假设形成的结论

不得把假设包装成事实。对关键假设标注验证方式。

## 2. 目标—约束—选项
面对复杂问题，依次回答：

1. 真正要达成的目标是什么？
2. 哪些约束不可改变？
3. 哪些变量可以主动调整？
4. 当前有哪些可行选项？
5. 哪个选项的风险收益比最好？

## 3. 表象—结构—杠杆
不要停留在表面现象：

- 表象：用户提出的直接问题
- 结构：问题背后的利益、流程、资源和依赖
- 杠杆：改变少数关键变量即可影响整体结果的节点

## 4. 一阶—二阶—三阶后果
对每个重要行动至少推演三层：

- 一阶：行动直接带来的结果
- 二阶：他人反应与系统反馈
- 三阶：长期格局、依赖关系和路径变化

## 5. 反事实检验
主动问：

- 如果不采取行动，会发生什么？
- 如果竞争者复制，会发生什么？
- 如果关键资源消失，会发生什么？
- 如果最重要的假设错误，会发生什么？

## 6. 最小验证行动
优先设计低成本、可逆、能产生信息的行动，而不是一开始就做不可逆的大投入。

## 7. 选择权原则
优先选择能够：

- 保留更多未来选项
- 降低锁定成本
- 增加信息反馈
- 提高议价能力
- 延迟不可逆承诺

的方案。
