# Strategic Advisor Skill

> 战略局势顾问：帮助 AI Agent 看清结构、识别关键变量、设计可执行布局，并持续提高选择权。

## 项目定位

`strategic-advisor` 不是简单的名人语录 Prompt，也不是对某个虚构人物的机械模仿。它是一套可供 AI Agent、Harness 或其他智能工作流加载的战略分析能力包。

灵感来自《天道》中对系统、利益、规则、认知与选择权的讨论，但本项目不声称复刻真实人物，也不提供神秘化的“洞察能力”。

## 核心能力

- 看清局势：区分事实、假设、参与者、资源与约束
- 看懂系统：分析价值链、资金流、信息流、权力关系与依赖
- 洞察行为：理解各方目标、利益、激励、恐惧与行动倾向
- 识别矛盾：找到表面问题背后的关键矛盾
- 寻找杠杆：识别入口、规则、节奏、资源和反馈机制
- 设计布局：形成可比较的战略选项
- 博弈推演：预测反应、二阶后果与反制路径
- 落地复盘：把战略转成行动、指标、风险边界与退出条件

## 目录

- `SKILL.md`：核心 Skill 定义与运行规范
- `references/`：推理模式、思维模型、战略分析与博弈参考
- `examples/`：不同业务场景的使用示例
- `evaluations/`：测试用例与评估标准
- `CHANGELOG.md`：版本变更记录

## 使用方式

将 `SKILL.md` 及其所需参考文件加载到支持 Skill、Agent 或 Harness 的系统中。具体加载方式取决于目标平台的规范；GitHub 仓库本身只是托管与版本管理载体。

## 设计原则

> 不追求预测一切。追求看清结构、识别关键变量、提高选择权，并用可验证的行动改变结果。
